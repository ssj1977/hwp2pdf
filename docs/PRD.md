# PRD

## 목적

한글 문서(HWP 계열)를 CLI/GUI에서 안정적으로 다른 문서 포맷으로 변환한다.

## 문제 정의

- 기존 도구는 GUI 중심 사용에 익숙하지만, 자동화/배치 작업에는 CLI 실행 검증이 필요하다.
- 설치 환경 의존성(.NET 타기팅 팩, 한글 COM 등록) 문제로 실행 실패가 자주 발생할 수 있다.

## 범위

- CLI 엔트리로 문서 변환 실행
- 입력 파일/폴더 수집 및 변환
- 대상 포맷 지원:
  - `PDF`, `HWP`, `HWPX`, `HWPML2X`, `HTML+`, `ODT`, `OOXML`, `UNICODE`, `RTF`

## 비범위

- 한글 프로그램 설치 자동화
- ODT 실패 원인 코드 수정(현재는 현상/재현만 기록)

## 성공 기준

- Release x86 빌드 성공
- `test.hwp` 기준 전체 대상 포맷 변환 명령 재현 가능
- 실패 사례 포함 트러블슈팅 문서화 완료
